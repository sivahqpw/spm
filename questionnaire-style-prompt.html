Prompt Template Generator

Create a structured questionnaire-style AI prompt template for [TASK].

Include numbered questions, multiple-choice options wherever appropriate, and "Answer Here:" fields.

The template should collect all the information the AI needs to produce a high-quality [OUTPUT].

Whenever applicable, provide comprehensive, mutually exclusive, and collectively exhaustive (MECE) answer options so the user has all relevant choices without significant omissions. Use predefined options instead of free-text fields whenever possible, and include free-text fields only when necessary for information that cannot reasonably be covered by predefined options.

Organize the questions in a logical order, avoid redundant questions, and ensure the completed questionnaire provides everything required for the AI to generate the best possible [OUTPUT].
